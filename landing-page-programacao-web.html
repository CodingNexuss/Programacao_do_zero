HTML — A Estrutura

  • Estrutura de uma página web
  • Textos, imagens e links
  • Listas, botões e formulários acessíveis

CSS — O Visual

  • Seletores, unidades e Box Model
  • Cores, fontes e espaçamento
  • Flexbox para layouts flexíveis
  • Grid para layouts em grade
  • Responsividade (Media Queries)
  • Animações com CSS

JavaScript — A Interatividade

  • Variáveis (let vs const)
  • Condições (if/else)
  • Funções reutilizáveis
  • Eventos (click, submit)
  • Manipulação do DOM
  • Console para encontrar erros

Git e Publicação

  • Git: versionamento de código
  • GitHub: armazenar projetos
  • GitHub Pages: publicar gratuitamente
  • Terminal e comandos básicos
